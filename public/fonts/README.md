# 本站字体

借鉴 [JYY Wiki 当前正文样式](https://jyywiki.cn/_next/static/css/f1360f1f2c658522.css)：Kalam 用于正文，Merienda One 用于标题，Fira Mono 用于代码。字体均在本站自托管，不依赖运行时 CDN 请求。

以下均为 Google Fonts 官方服务提供的、未经本站修改的 Regular 400 Latin WOFF2 子集，取得于 2026-11-03。中文由 `src/styles/typography.css` 中明确列出的本机字体回退显示；这三款字体不提供中文字形。

| 本地文件 | 官方下载来源 | 许可证 |
| --- | --- | --- |
| `kalam-latin-regular.woff2` | [Kalam v18](https://fonts.gstatic.com/s/kalam/v18/YA9dr0Wd4kDdMthROCc.woff2) | `kalam-OFL.txt` |
| `merienda-one-latin-regular.woff2` | [Merienda One v18](https://fonts.gstatic.com/s/meriendaone/v18/H4cgBXaMndbflEq6kyZ1ht6ohYaz.woff2) | `merienda-one-OFL.txt` |
| `fira-mono-latin-regular.woff2` | [Fira Mono v16](https://fonts.gstatic.com/s/firamono/v16/N0bX2SlFPv1weGeLZDtgJv7S.woff2) | `fira-mono-OFL.txt` |

下载地址经官方 CSS 核对：[Kalam 与 Fira Mono](https://fonts.googleapis.com/css2?family=Fira+Mono&family=Kalam&display=swap)、[Merienda One](https://fonts.googleapis.com/css2?family=Merienda+One&display=swap)。选择 Latin 子集以减少体积；未覆盖的字符由系统回退显示。

三款字体均采用 SIL Open Font License 1.1，完整版权和许可保存在对应的 `*-OFL.txt` 中。许可证原件来自 Google Fonts：[Kalam](https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/OFL.txt)、[Fira Mono](https://raw.githubusercontent.com/google/fonts/main/ofl/firamono/OFL.txt)、[Merienda One 固定历史版本](https://raw.githubusercontent.com/google/fonts/be2838a23fd2918408e22b25c54135da76525ff6/ofl/meriendaone/OFL.txt)。Merienda One 已从仓库当前目录移除，因此保留历史来源；它与新版 Merienda 不是同一个字体文件。
